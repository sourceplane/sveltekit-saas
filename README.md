# sveltekit-saas

[CMSaasStarter](https://github.com/scosman/CMSaasStarter) — Steve Cosman's
SvelteKit SaaS template: a pre-rendered marketing site, a blog, search,
pricing, Supabase Auth, an account dashboard, Stripe billing and email — on
**Cloudflare Workers + Static Assets** through
[`@sveltejs/adapter-cloudflare`](https://svelte.dev/docs/kit/adapter-cloudflare),
with a **Supabase** project per environment provisioned by Terraform through
[Orun](https://github.com/sourceplane/orun), and packaged, once it is built,
as an **Orun baseline**.

Being built in reviewed steps; the plan and its status are in
[`specs/epics/sveltekit-saas`](specs/epics/sveltekit-saas/README.md).
